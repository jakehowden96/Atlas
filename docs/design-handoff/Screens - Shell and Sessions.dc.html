Shell and Sessions

Top bar, Sessions grid and tile, the Session view, and app-level states, at 1400 / 1100 / 800 in both themes. Built only from the component sheet.

1 · Top bar

The mark replaces the text-only wordmark. The status line degrades in steps instead of clipping: 1400 shows all four counts; 1100 drops idle and spend (still in the tooltip); 800 becomes a compact count chip with shapes. Jump collapses to an icon button with ⌘K. The live dot appears only while something runs. Notifications holds toast history. On macOS the bar itself is the drag region with a 76px inset for the traffic lights, replacing the separate 28px strip; on Windows the native title bar sits above, unchanged.

2 · Sessions grid and tile

The tile is an article, not a button: its label is the link that opens it, and pin, close, Deny and Allow are sibling buttons (no nested interactive). Grid keeps roving focus and y/n. Hover is a --border2 ring with no shadow; focus is the --focus ring, not accent. Pin and close are always visible at --muted (24px targets) instead of appearing on hover. The workspace is a swatch beside --text. Diff counts hide at +0 −0. The amber action bar stays: it is the one place a fill carries state, and it always holds words.

3 · Session view

Header: back is an icon button with the chord in its tooltip; the N switch dots become one "Other sessions" menu button showing counts by shape (opens the Jump list scoped to running sessions); ▥ becomes the rail toggle icon. Footer keeps the last tool and the tail state only; totals live in the rail header and are not repeated. At 800 × 500 the rail starts thin and the header drops the branch and the Changes label.

4 · App-level states

Each is one banner or one centred state, never a new layout. Blocking problems (Claude Code missing) take the content area; degrading ones (hooks, tailing) are banners above the grid; good news (update ready) is a quiet top-bar notice. The window background is read from the saved theme before first paint, so light users no longer see a dark flash.
