Rules
OrderInfo is a pinned header, not a tile: the ticket on --surface2, then context, cost and elapsed on a --surface3 meter strip with a full-bleed context line. It never collapses or scrolls, and keeps its height with no ticket linked. Below it, Plan, Agents and PR never reorder or disappear; an empty tile keeps its one line.
Auto-openA tile opens by itself when something in it is running, failed or needs attention, and collapses when it settles. Clicking a header overrides that for the rest of the session.
CollapsedEach tile is a sentence: what state, then what it is about, two lines at most. Read top to bottom, the collapsed rail tells the whole situation without opening anything.
ExpandedEvery item is a row: dot, a title that wraps to two lines, then a status word and what it is doing. Rows group running first, then needs attention, then done, which folds into one “n done” row you can open.
WaitingWhen the session needs you, a one-line --warn strip sits on the header's top edge. It is session-level only; subagent prompts go to the orchestrator, so agent rows never say “needs you”.
ScaleEvery list in an open tile shows 3 rows, then “+n more” that expands inline. Passed checks and done agents fold into one row. At 48px the rail keeps the ticket ID and one dot per tile.
TruncationTitles wrap and clamp only after two lines. Single-line ellipsis is reserved for file paths and branch chips. Status words and numbers never truncate. Branch chips appear only when the session spans more than one worktree.
